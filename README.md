# SiloSave

**Save supported media in your browser, or manage larger downloads on your computer.**

SiloSave makes it easier to keep videos and other media that you own or are allowed to save.

### Choose how you want to save

| Product | What it does | Where to start |
| --- | --- | --- |
| **SiloSave Web** | Free web tool for supported public media links. | **[Use SiloSave Web](https://silosave.com/)** |
| **SiloSave Desktop** | Local-first desktop app for batch downloads, supported account backups, and download management. Windows release and macOS preview available. | **[Explore Desktop](https://silosave.com/desktop)** |

### Official releases

**[SiloSave Desktop installers, checksums, and release notes](https://github.com/silosaveapp/silosave-desktop-downloads)**

Downloads and local media processing run on your own computer in the Desktop app. Website functionality, platform compatibility, and licensing details are documented on [silosave.com](https://silosave.com/).

Have a reproducible Desktop issue? [Report it here](https://github.com/silosaveapp/silosave-desktop-downloads/issues/new). Please do not post private URLs, login cookies, or license codes.

**SiloSave is a proprietary product.** The public downloads repository provides official binaries; it is not an open-source code repository.
